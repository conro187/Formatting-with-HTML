# Data 
	Vectors: A vector is the most basic data structure in R. It contains a list of items of the same type 
	Lists: A list can hold different data types in a single structure. You can combine numbers, strings, vectors, and even other lists 
	Matrices: A matrix is a 2D data structure where all elements are of the same type. It is like a table with rows and columns	
	Arrays: An array is like a matrix, but can have more than two dimensions. It stores elements of the same type in multiple dimensions 
	Data Frames are tables in a spreadsheet that can hold different amounts of data
